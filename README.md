# Solaris Discord Client\n\nA minimal Firefox-based Discord client with a separate persistent Firefox profile. It uses no npm packages, frameworks, or downloaded libraries.\n\n## Run\n\n```sh\ncd /export/home/solaris/git/discord-client\n./launch-firefox.sh\n```\n\nThe launcher opens `https://discord.com/app` with Firefox `-no-remote` and a dedicated profile.\n\n## Separate profile\n\nBy default, Discord data is stored in:\n\n```text\n~/.discord-firefox-profile\n```\n\nThis profile is separate from your normal Firefox profile and contains Discord cookies, login/session state, Local Storage, IndexedDB, cache, and other Firefox data for this client.\n\nChoose another location with:\n\n```sh\nDISCORD_PROFILE=\"$HOME/secure/discord-profile\" ./launch-firefox.sh\n```\n\nThe launcher creates the profile with restrictive permissions where supported. Profile separation is isolation, not custom encryption. Anyone who can read the profile may be able to access session data; use an encrypted filesystem and normal OS permissions for stronger protection. Do not commit or share the profile directory.\n\n## External links\n\nThe extension keeps Discord and DiscordApp links in Firefox. Other HTTP(S) links are opened in a normal Firefox tab.\n\n## Temporary extension install\n\n1. Open Firefox and visit `about:debugging`.\n2. Select **This Firefox** and **Load Temporary Add-on**.\n3. Select this repository `manifest.json`.\n4. Run `./launch-firefox.sh`.\n
